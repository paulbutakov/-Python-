# 📚 Проверка гипотез: активность чтения в Москве vs Санкт-Петербурге

## 🔎 Описание
Проект по проверке статистической гипотезы на пользовательских данных: сравнение
активности пользователей из **Москвы** и **Санкт-Петербурга** по суммарному времени активности (часы).

Цель — показать полный цикл **hypothesis testing в Python**: формулировка гипотез,
подготовка данных, выбор критерия и интерпретация результата для бизнеса.

---

## 🎯 Цели
- Сформулировать нулевую и альтернативную гипотезы
- Подготовить данные и проверить предпосылки применимости критериев
- Выбрать и применить статистический тест (параметрический / непараметрический)
- Интерпретировать результат (p-value, размер эффекта) и сформулировать вывод

---

## 📦 Данные
- Сущности: пользователи из Москвы и Санкт-Петербурга
- Метрика: суммарные часы активности пользователя за период наблюдения

> Исходные данные использовались в учебных целях и **не хранятся в репозитории**.
> В репозитории оставлены только мой код, расчёты, визуализации и выводы.

## 🧠 Что сделано
- Проведён EDA и проверка качества данных
- Проверены предпосылки (распределения, выбросы — в зависимости от кейса)
- Выбран критерий для сравнения двух независимых выборок
- Выполнена проверка гипотез и интерпретация результата
- Оформлена аналитическая записка с выводами для принятия решения
